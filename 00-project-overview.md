# Grower Portal Research — Project Overview

*Last updated: 2026-09-21*

## What this project is

A working knowledge base for AgVend's Customer (Grower) Portal research effort, kicked off June 2026. It exists to:

1. Import the context the team has already built (Slack discussion, interview notes, the Figma synthesis board, prior survey data) into one place.
2. Produce a shareable summary of findings for research participants (the 10 partner companies who helped set up interviews).
3. Serve as the planning base for the next research phase: interviews directly with **partner growers** (rather than partner staff/PSMs).

## Source material imported into this project

- `01-research-methodology.md` — who was interviewed, how partners/personas were selected, and the research questions used
- `02-survey-insights-baseline.md` — existing AgVend knowledge-base summary of 2,015+ in-portal grower survey responses (Sept 2022–Mar 2025), used as a baseline before this round of qualitative research. This was not considered a part of the Grower Portal Research that we are refering to in this project that was specific to interviews. 
- `03-interview-synthesis.md` — Figma theme clusters, verbatim quotes, and cross-cutting patterns from the interviews
- `04-next-phase-grower-research-plan.md` — planning doc for the next round, this time with partner growers directly
- `transcripts/` — one file per completed interview; add Granola / Fireflies / Drive links here so Figma is not the archive
