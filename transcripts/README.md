# Interview sources

This folder is the local archive for **what we have from each call**. The Figma board and `03-interview-synthesis.md` stay the clustering layer.

## What counts as “enough”

This repo stores text only. It does not store audio or video.

1. **Transcript text.** The copied speaker turns (Fireflies view paste, or a Granola export that still had the transcript). Prefer this over a summary when you have it.
2. **Notes substitute.** Granola (or Fireflies) AI summary, copied into the interview file. Use this when the transcript text is gone. Do not keep hunting `/t/` chat links or re-pasting the same summary. MCP can refresh summaries from `/d/` notes; it cannot recover deleted transcript text.
3. **Empty.** No transcript text and no notes. Still a hole.

Notes are paraphrase, not quotes. Do not treat summary bullets as verbatim speech. Site quotes that came from a summary should say so in `sourceLabel`.

## How to add material

- **Fireflies:** paste the view URL plus transcript (or notes if that is all that exists).
- **Granola:** MCP can pull attendees and the summary. If you still have a transcript export, paste it. If you only have the summary, that is the substitute. Stop there.
